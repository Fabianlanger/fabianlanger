# Profile assets

- `profile.svg`, `linkedin-button.svg`, `website-button.svg`, `experience.svg` and `education.svg` are generated by `python scripts/build_profile.py`.
- Edit public profile content in `data/profile.json`. Dates and roles were transcribed from the supplied LinkedIn exports; the requested headline and Enexis summary follow Fabian's instructions. Respectzorg is split at the October 2021 consultancy transition. Timeline spacing is editorial, not proportional to elapsed time.
- Company and university logos are the original organisation images from the supplied LinkedIn export. The full IBS logo comes from the IBS house-style asset pack. Logos retain their original colours and proportions.
- Poppins Light, Regular and SemiBold are included with their SIL Open Font License in `fonts/OFL.txt`. The generator converts text to vector paths, so GitHub does not need remote fonts. SVG descriptions and the README text version provide readable alternatives.
- The Y2K metallic and transparent-panel treatment is a requested extension of the IBS palette. Source HTML, extracted full-page text and local browser previews are excluded by `.gitignore`.

Build dependency: `python -m pip install -r scripts/requirements.txt`.
